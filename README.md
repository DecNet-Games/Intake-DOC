# Intake-DOC

Documentation site source for **Intake — AI Model Refinery: Folder-In, Prefab-Out with Report Cards** by Decnet Games.

Built with Jekyll + [Just the Docs](https://just-the-docs.com/) (loaded via `remote_theme`) and published with GitHub Pages at:

**https://decnet-games.github.io/Intake-DOC/**

## Layout

- `index.md` — Home
- `docs/` — Getting Started, Installation, Quick Start, The Home Window, One-Click Setup, The Inbox Workflow, Triangle Budgets, LOD Chains, Convex Colliders, Scale, Pivot & Grounding, Textures & Materials, Report Cards, Formats — FBX, OBJ and glTF, The Messy Crate Test, Profiles, What v1 Is Not, FAQ, Troubleshooting, Changelog, Support
- No `assets/` media: this tree ships zero screenshots by design (the MergeGuard-DOC precedent — text-first documentation). Screenshots join the tree only after real Editor captures exist; documentation never ships invented imagery.

Intake itself is sold exclusively through the Unity Asset Store (publisher: Decnet Games). Nothing in this repository is the product — this repo is documentation only.
