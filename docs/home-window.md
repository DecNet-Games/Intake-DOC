# The Home Window
{: .no_toc }

**Tools → Decnet Games → Intake** opens Intake Home. Everything Intake does lives in this one window.

## Welcome

The welcome screen's quick actions **run setup**, **start the Messy Crate Test**, and **open the documentation and support pages** — the three things a first-run user needs, before any queue exists.

## Intake Queue

The working surface: the Inbox census with every model's **real triangle count**, the category assigned to each model, and the **Run Intake** action. A run is cancelable, and it reports its progress **per asset** while it works — a batch of dense models is minutes of work, and the queue says where it is. See [The Inbox Workflow]({{ site.baseurl }}/docs/inbox-workflow/).

## Report Cards

The card browser: every asset Intake has processed, with its full [report card]({{ site.baseurl }}/docs/report-cards/) — classification, budget verdict, and every change with before/after values. Batch exports (Markdown and JSON) start here.

## Profiles

The category profiles — triangle budget, texture ceiling, LOD behaviour per category — all **buyer-editable**, with profile duplication for your own variants. Your edits **persist across setup runs**. See [Profiles]({{ site.baseurl }}/docs/profiles/).

## Settings

Intake's own configuration for the window and the pipeline, in the same place as everything else.
