# Support
{: .no_toc }

## Email

**support@decnetgames.com** — the support address for Intake and every Decnet Games product. When you write, attach the asset's **report card** (or the batch Markdown export): the card records the profile judged against, every change and every verdict, which makes a report answerable instead of speculative.

## Community

- **Discord** — [discord.gg/P9wepz7NBW](https://discord.gg/P9wepz7NBW)
- **Other Decnet Games assets** — [the publisher page](https://assetstore.unity.com/publishers/118262) on the Unity Asset Store.

## Before you write

- [Troubleshooting]({{ site.baseurl }}/docs/troubleshooting/) covers the outcomes Intake reports about itself: Over budget, Needs human pass, a failed asset, a Not supported glTF file, and slow runs on dense meshes.
- [What v1 Is Not]({{ site.baseurl }}/docs/what-v1-is-not/) is the boundary list — if the thing you need is on it (retopology, character meshes, glTF processing), it is a v1 boundary, not a bug.
